
# Student Marks Calculator

## Description
A Python project that calculates a student's total,
average, percentage, and grade.

## Features
- Accepts a student's name
- Takes marks for five subjects
- Validates marks between 0 and 100
- Handles invalid numeric input
- Calculates total, average, and percentage
- Assigns a grade automatically

## Technology
- Python

## How to Run
python student_marks.py
